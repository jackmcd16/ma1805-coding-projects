# 04 MEDIA - Knights of Guinevere
I was initially inspired by the mechanics of an online example I personally found, and combined it with a piece of media I enjoy that I felt tonally worked.

I first used the preload function to load all the images and audio to use later in the code - being 2 pieces of art and audio from Knights of Guinevere's original teaser trailer. At the start, the happy image is displayed and both musics are added; the scary music is set at 0 volume.

I followed the example to use the copy command to copy over the scary image on top of the happy image. This mimics the teaser trailer, where it dramatically cut from the happy scene to the gruesome scene, while keeping a similar camera angle.

As the mouse is dragged, it also increases the distortion variable by a small amount each square made. This reduces the happy music and increases the scary ambiance noise, letting it naturally grow louder as the user reveals more of the dark image.
(The audio was very unreliable, sometimes randomly not working even if the code isn't changed at all.)
