# 01 DRAWING - PUMPKIN EMOJI
I created a basic pumpkin to celebrate the Halloween season it was made in.

I used several ellipses to make the body, changing the colour of them to add depth with shadows and highlights. Additionally, I used 3 triangles to create the stem. The main challenge was properly ordering the command so that certain parts were above overs, such as moving the stem triangles to before the ellipses so the stem would be behind.

The mouth was created by 2 arcs, with 2 circles in the centre of them to make it only the thick outline. I learned that I could not use the erase command to remove their centres as it deletes everything behind it, leaving a white hole.

When I first programmed it, I was unaware the noStroke command applied to everything after it. To refine the code, I removed all the noStrokes and added it once to the setup, making it so it applies to everything.
